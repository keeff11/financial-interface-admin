# Financial Interface Admin

보험사 금융 IT 인터페이스 통합관리시스템 MVP 프로젝트입니다.

내부 핵심 시스템과 외부 기관(금감원, 제휴사 등) 간 다양한 인터페이스를  
하나의 화면에서 등록, 실행, 모니터링, 제어, 재처리할 수 있도록 구현했습니다.

---

## 1. 프로젝트 소개

금융/보험 시스템은 외부 기관과 다양한 방식으로 연계됩니다.  
대표적으로 REST API, SOAP, MQ, Batch, SFTP/FTP 같은 서로 다른 프로토콜이 함께 사용됩니다.

이 프로젝트는 이러한 인터페이스를 개별적으로 관리하는 대신,  
운영자가 단일 화면에서 다음 기능을 수행할 수 있는 통합관리 플랫폼을 목표로 했습니다.

- 인터페이스 등록
- 활성 / 비활성 제어
- 수동 실행
- 자동 점검
- 실행 로그 확인
- 실패 건 재처리
- 상태 및 응답속도 모니터링

---

## 2. 주요 기능

### 인터페이스 등록 및 관리
- 기관명, API명, 프로토콜, 대상 URL 등록
- 활성 / 비활성(On/Off) 제어

### 실행 및 제어
- 수동 실행 기능
- 활성화된 인터페이스 대상 자동 점검 스케줄링

### 로그 및 모니터링
- 실행 결과 로그 저장
- SUCCESS / FAIL / DELAY 상태 관리
- 응답속도 및 에러 메시지 확인
- 최근 로그 조회 및 상세 조회

### 재처리
- 실패 또는 지연 로그에 대한 재처리 기능 제공
- 재처리 이력 추적 가능

### 프로토콜별 실행 분리
- REST
- SOAP
- MQ
- BATCH
- SFTP
- FTP

각 프로토콜은 executor 분리 구조로 설계하여 확장 가능하도록 구현했습니다.

## 5. 실행 방법

## 5-1. Backend 실행

```bash
cd backend
./gradlew bootRun
```

또는 Windows 환경에서는:

```bash
gradlew.bat bootRun
```

기본 포트:

* `http://localhost:8080`

---

## 5-2. Frontend 실행

```bash
cd frontend
npm install
npm run dev
```

기본 포트:

* `http://localhost:3000`

## 6. 테스트 방법

### 1) 인터페이스 등록

* API 등록 화면에서 기관명, API명, 프로토콜, URL 입력 후 등록

### 2) 수동 실행

* 등록된 인터페이스의 실행 버튼 클릭
* 실행 결과가 로그에 저장되는지 확인

### 3) 자동 점검

* 활성화된 인터페이스를 대상으로 스케줄러가 주기적으로 점검 수행
* 생성된 로그를 대시보드에서 확인

### 4) 재처리

* FAIL 또는 DELAY 로그 선택
* 재처리 버튼 클릭
* 새로운 로그가 생성되는지 확인

### 5) 로그 필터 / 상세 조회

* 상태, 프로토콜, 키워드 기준 필터 확인
* 개별 로그 상세 정보 확인

---

## 7. 상태 테스트 예시

등록 시 `targetUrl` 값에 따라 테스트 시나리오를 구분할 수 있도록 구성했습니다.

* `success` 포함: 성공 위주 동작
* `fail` 포함: 실패 유도
* `delay` 또는 `timeout` 포함: 지연 유도

예시:

* `https://fake-success/api`
* `https://fake-fail/api`
* `https://fake-delay/api`

## 8. 구현 의도

이 프로젝트는 다양한 프로토콜을 실제 외부 기관과 모두 실연동하는 것보다,
**통합관리 플랫폼의 핵심 운영 흐름**을 구현하는 데 초점을 맞췄습니다.

즉, 다음 흐름이 자연스럽게 이어지도록 설계했습니다.

1. 인터페이스 등록
2. 실행 / 자동 점검
3. 상태 및 로그 확인
4. 실패 건 재처리
5. 운영자가 단일 화면에서 제어

---

## 9. 한계 및 확장 방향

현재 구현은 과제 환경과 시간 제약을 고려하여
실제 외부 기관과의 실통신 대신 mock / fake executor 기반으로 단순화했습니다.

### 현재 한계

* 실제 SOAP 서버 연동 미구현
* 실제 MQ 브로커 연동 미구현
* 실제 SFTP/FTP 서버 연동 미구현
* Batch 전용 세부 스케줄 설정 단순화

### 확장 방향

* 프로토콜별 실제 통신 모듈 연결
* MQ queue / topic 설정 추가
* Batch cron 설정 추가
* SFTP remote path 및 파일 이력 관리 추가
* 사용자 권한 및 운영 이력 관리 추가
